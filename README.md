# Mahad Khadijah School Management Prototype

A frontend-only Next.js demo for school administration and the teacher workspace. All records are fictional and supplied by local mock services. There is no authentication, backend API, or database connection; changes are temporary and do not persist after the browser session.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The home page opens the teacher dashboard. Other school screens are available through the application navigation.

## Demo boundaries

- Student, teacher, attendance, memorisation, and report data are mock data.
- Form interactions are local demonstrations and do not create persistent records.
- Authentication and backend integrations must be added separately when the backend contract is ready.
